# Personal Meta Ads AI Agent

An AI-powered assistant and tutor designed to help me plan, write, target, and analyze Meta (Facebook & Instagram) Ads while teaching me best practices.

## Tech Stack
- **Frontend:** HTML, CSS, Vanilla JavaScript (Hosted on Vercel)
- **Backend:** Python + FastAPI (Hosted on Render)
- **AI Models:** Groq & Google Gemini (Free Tier)
